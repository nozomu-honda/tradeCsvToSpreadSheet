## 2. 保有数

- 初期値は `0`
- 銘柄ごとに累積計算する

| 取引区分 | 処理 |
|---|---|
| 現物買付 | 数量を加算 |
| 現物再投 | 数量を加算 |
| 入庫（増減資） | 数量を加算 |
| 現物募集 | 数量を加算 |
| 株転換取得（買） | 数量を加算 |
| 現物売却 | 数量を減算 |
| 現物買取 | 数量を減算 |
| 強制償還（売） | 数量を減算 |
| 入金（利金） | 何もしない |
| 入金（配当金） | 何もしない |
| 入金（分配金） | 何もしない |
| 償還 | 何もしない |
| その他 | アラート |

## 3. 手数料の消費税額

| 取引区分 | 計算 |
|---|---|
| 現物買付 | `floor(手数料 / 1.1 * 0.1)` |
| 現物再投 | `0` |
| その他 | 空欄 |

## 4. 平均取得単価

### 4.1 対象取引

- 現物買付
- 現物再投
- 現物募集
- 株転換取得（買）

### 4.2 何もしない取引

- 現物売却
- 現物買取
- 入庫（増減資）
- 強制償還（売）
- 入金（利金）
- 入金（配当金）
- 入金（分配金）
- 償還

### 4.3 その他

- アラート

### 4.4 計算式

- 直前の銘柄ごとの残高が 0 より大きい場合  
  `平均取得単価 = (直前の銘柄ごとの残高 + 簿価) / 保有数`

- それ以外  
  `平均取得単価 = 簿価 / 保有数`

### 4.5 保持・表示ルール

- 内部値は小数のまま保持する
- 表示は整数表示とする
- 平均取得単価そのものを先に丸めて別計算に使わない

- 現物買取

### 5.2 計算式

- それ以外: `単価 × 数量`

### 5.3 その他

## 6. 取得価格（acquisitionPrice）

### 6.1 対象

- 現物売却
- 現物買取

### 6.2 計算式

- 株式: `直前の平均取得単価 × 数量`
- 投信: `直前の平均取得単価 × 数量 / 10000`

### 6.3 その他

- 空欄

## 7. 売却損益

### 7.1 対象

- 現物売却
- 現物買取

### 7.2 計算式

`売却損益 = 手数料抜き売値 - 取得価格`

### 7.3 その他

- 空欄

## 8. 簿価

### 8.1 現物買付 / 現物再投 / 現物募集

- 決済通貨が `JPY` 以外の場合  
  `受渡金額 × レート - 手数料の消費税額 × レート`

- レート未入力の場合
  - アラートを出す
  - 暫定計算は `受渡金額 - 手数料の消費税額`

- 決済通貨が `JPY` または空欄の場合  
  `受渡金額 - 手数料の消費税額`

### 8.2 現物売却 / 現物買取

簿価は、平均取得単価を丸めた値ではなく、**取得価格（acquisitionPrice）** を基準に計算する。

**計算式**

`簿価 = 取得価格 × (-1)`

**注意**

- 平均取得単価を先に切り上げ・切り捨て・四捨五入して簿価を計算してはならない
- `roundedAvg` などの丸め済み単価は簿価計算に使用しない
- 現物売却 / 現物買取は対象取引として扱う
- ただし平均取得単価が無い場合は、**「対象外」ではなく「平均取得単価が未計算」** とアラートする

### 8.3 株転換取得（買）

- 決済通貨が `JPY` 以外の場合  
  `受渡金額 × レート`

- レート未入力の場合
  - アラートを出す
  - 暫定計算は `受渡金額`

- 決済通貨が `JPY` または空欄の場合  
  `受渡金額`

### 8.4 強制償還（売）

`簿価 = 受渡金額 × (-1)`

### 8.5 入庫（増減資） / 入金（利金） / 入金（配当金） / 入金（分配金） / 償還

- 何もしない

### 8.6 その他

- アラートを出す

## 9. 銘柄ごとの残高

### 9.1 対象

- 現物買付
- 現物再投
- 現物売却
- 現物買取
- 現物募集

### 9.2 計算式

`銘柄ごとの残高 = 直前の銘柄ごとの残高 + 簿価`

### 9.3 何もしない取引

- 入庫（増減資）
- 入金（利金）
- 入金（配当金）
- 入金（分配金）
- 株転換取得（買）
- 強制償還（売）
- 償還

### 9.4 その他

- アラート

### 9.5 保持ルール

- 計算後の値は整数化する
