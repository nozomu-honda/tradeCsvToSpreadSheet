## 2. 保有数

- 初期値は `0`
- 銘柄ごとに累積計算する

| 取引区分 | 処理 |
|---|---|
| 現物買付 | 数量を加算 |
| 現物再投 | 数量を加算 |
| 入庫（増減資） | 数量を加算 |
| 現物募集 | 数量を加算 |
| 株転換取得（買） | 数量を加算 |
| 現物売却 | 数量を減算 |
| 現物買取 | 数量を減算 |
| 強制償還（売） | 数量を減算 |
| 償還 | 一つ前の保有数が0なら何もしない / それ以外は数量を減算 |
| 入金（利金） | 何もしない |
| 入金（配当金） | 何もしない |
| 入金（分配金） | 何もしない |
| その他 | アラート |

---

## 3. 手数料の消費税額

| 条件 | 計算 |
|---|---|
| `国内消費税等（円）` に値がある | その値をそのまま使う |
| 上記以外かつ 現物買付 | `floor(手数料 / 1.1 * 0.1)` |
| 上記以外かつ 現物再投 | `0` |
| その他 | 空欄 |

## 4. 平均取得単価

### 4.1 対象取引

- 現物買付
- 現物再投
- 現物募集
- 株転換取得（買）

### 4.2 何もしない取引

- 現物売却
- 現物買取
- 入庫（増減資）
- 強制償還（売）
- 償還
- 入金（利金）
- 入金（配当金）
- 入金（分配金）

### 4.3 その他

- アラート

### 4.4 計算式

- 直前の銘柄ごとの残高が 0 より大きい場合  
  `平均取得単価 = (直前の銘柄ごとの残高 + 簿価) / 保有数`

- それ以外  
  `平均取得単価 = 簿価 / 保有数`

### 4.5 投信の扱い

- 商品が `投信` の場合は **10000口基準** で計算する
- 商品が `投信` 以外の場合は従来どおり 1口 / 1株基準で計算する

### 4.6 保持・表示ルール

- 内部値は小数のまま保持する
- 表示は整数表示とする
- 平均取得単価そのものを先に丸めて別計算に使わない

---

## 5. 手数料抜き売値

### 5.1 現物売却 / 現物買取

- 投信: `単価 × 数量 / 10000`
- それ以外: `単価 × 数量`

### 5.2 償還

- 一つ前の保有数が0なら何もしない
- それ以外
  - 投信: `単価 × 数量 / 10000`
  - それ以外: `単価 × 数量`

### 5.3 強制償還（売）

- `受渡金額/決済損益`

### 5.4 その他

- 空欄

---

## 6. 取得価格（acquisitionPrice）

### 6.1 現物売却 / 現物買取 / 強制償還（売）

- 株式: `直前の平均取得単価 × 数量`
- 投信: `直前の平均取得単価 × 数量 / 10000`

### 6.2 償還

- 一つ前の保有数が0なら何もしない
- それ以外
  - 株式: `直前の平均取得単価 × 数量`
  - 投信: `直前の平均取得単価 × 数量 / 10000`

### 6.3 その他

- 空欄

---

## 7. 売却損益

### 7.1 現物売却 / 現物買取 / 強制償還（売）

`売却損益 = 手数料抜き売値 - 取得価格`

### 7.2 償還

- 一つ前の保有数が0なら何もしない
- それ以外
  - `売却損益 = 手数料抜き売値 - 取得価格`

### 7.3 その他

- 空欄

---

## 8. 簿価

### 8.1 現物買付 / 現物再投 / 現物募集

- 決済通貨が `JPY` 以外の場合  
  `受渡金額 × レート - 手数料の消費税額 × レート`

- レート未入力の場合
  - アラートを出す
  - 暫定計算は `受渡金額 - 手数料の消費税額`

- 決済通貨が `JPY` または空欄の場合  
  `受渡金額 - 手数料の消費税額`

### 8.2 株転換取得（買）

- 決済通貨が `JPY` 以外の場合  
  `受渡金額 × レート`

- レート未入力の場合
  - アラートを出す
  - 暫定計算は `受渡金額`

- 決済通貨が `JPY` または空欄の場合  
  `受渡金額`

### 8.3 現物売却 / 現物買取 / 強制償還（売）

簿価は **取得価格（acquisitionPrice）** を基準に計算する。

`簿価 = 取得価格 × (-1)`

- 平均取得単価を先に丸めた値は使わない
- 平均取得単価が無い場合は「平均取得単価が未計算」とアラートする

### 8.4 償還

- 一つ前の保有数が0の場合
  - `受渡金額/決済損益`
- それ以外
  - `簿価 = 取得価格 × (-1)`

### 8.5 入庫（増減資） / 入金（利金） / 入金（配当金） / 入金（分配金）

- 何もしない

### 8.6 その他

- アラートを出す

---

## 9. 銘柄ごとの残高

### 9.1 対象

- 現物買付
- 現物再投
- 現物売却
- 現物買取
- 現物募集
- 強制償還（売）

### 9.2 計算式

- 上記対象取引  
  `銘柄ごとの残高 = 直前の銘柄ごとの残高 + 簿価`

- 償還
  - 一つ前の保有数が0なら何もしない
  - それ以外
    - `銘柄ごとの残高 = 直前の銘柄ごとの残高 + 簿価`

### 9.3 何もしない取引

- 入庫（増減資）
- 入金（利金）
- 入金（配当金）
- 入金（分配金）
- 株転換取得（買）

### 9.4 その他

- アラート

### 9.5 保持ルール

- 計算後の値は整数表示とする
- `-0` は `0` に正規化する

## 12. 手入力税列

### 12.1 国内消費税等（円）

- `手数料の消費税額` の計算にだけ使う
- 簿価計算にもその影響を反映する

### 12.2 現地源泉税（円） / 国内源泉所得税（円） / 国内源泉地方税（円）

- 入力を受け付ける
- DBに保持する
- 出力シートにそのまま出す
- 現時点では各種計算には使用しない
