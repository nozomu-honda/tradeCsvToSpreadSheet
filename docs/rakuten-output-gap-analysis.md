# 楽天アウトプット差分整理

作成日: 2026-07-08

## 対象

Google Drive 側の仕様:

- `楽天インプット用`
- `1_楽天アウトプット用_もともとcsvにあるもの`
- `2_楽天アウトプット用_追加したカラムで載せるもの`
- `3_楽天アウトプット用_ 計算して載せたいもの`
- `4_楽天アウトプット用_最終的な見た目`

現状実装・既存 docs:

- `src/app/source_routing_rakuten_phase1.gs`
- 楽天DB: `src/app/db_config.gs` / `src/app/db.gs`
- 楽天出力入口: `buildRakutenOutputSheetsFromDbRecords_()` / `buildRakutenOutputSheetsFromBaseRecords_()`
- `docs/trade-rules.md`
- `docs/spec.md`

## 要約

- 楽天入力は、日本株・米国株・投信・配当金/分配金・入出金履歴の5種類を検出し、共通計算モデルへ正規化する入口は実装済み。
- 楽天DBは `RAKUTEN_DB_HEADERS` で保存するところまで進んでいるが、現状は共通計算モデルへ一度丸めた後に楽天DBへ保存するため、Drive 仕様が要求する一部の元CSV列は失われる。
- 楽天出力入口はあるが、出力本体はまだ共通の6シート出力を使っている。Drive 仕様の `楽天日本株` / `楽天米国株` / `楽天投資信託` / 最終見た目の列順・表示対象は未実装。
- 計算列は共通計算コアで近い列を出せるが、米国株の `税金[USドル] * 為替レート`、投信の追加手入力列、Drive 仕様上の簿価式などは現状実装と差分がある。

## 計算列対応状況

| 計算列 | Drive 仕様の要点 | 現状実装 | 判定 | 差分・注意点 |
|---|---|---|---|---|
| 保有数 | 買付/入庫で加算、売付/解約で減算 | 共通計算コアで `現物買付`、`現物再投`、`入庫（増減資）` は加算、`現物売却`、`現物買取` は減算 | 概ね対応 | 楽天の元売買区分ではなく、正規化後の共通取引区分を前提に計算する |
| 手数料の消費税額 | 日本株は `税金等[円]`、米国株は `税金[USドル] * 為替レート`、投信は `国内消費税等（円）` | `国内消費税等（円）` があれば優先、なければ買付時に `手数料（税込）` から概算 | 一部対応 | 日本株は `税金等[円]` を `国内消費税等（円）` に入れるため近い。米国株の `税金[USドル]` は未保持。投信の `国内消費税等（円）` 追加入力は未実装 |
| 平均取得単価 | 銘柄ごとに直近平均取得単価・保有数・簿価から算出。投信は口数/10000前提 | 共通計算コアで銘柄ごとに算出。投信は 10000 口単位で計算 | 概ね対応 | 算出元の簿価が Drive 仕様とずれる場合、平均取得単価も連動してずれる |
| 手数料抜き売値 | 日本株は数量*単価、米国株は約定代金*為替レート、投信は数量/10000*単価 | 共通計算コアで日本株は数量*単価、外株は数量*単価*レート、投信は数量*単価/10000 | 概ね対応 | 米国株は `約定代金[USドル]` を直接使わず、数量*単価で再計算する |
| 取得価格 | 売却/解約時に平均取得単価*数量。投信は数量/10000 | 共通計算コアで算出 | 対応済み | 前提となる平均取得単価の差分に依存 |
| 売却損益 | 手数料抜き売値 - 取得価格 | 共通計算コアで算出 | 対応済み | 前提となる手数料抜き売値・取得価格の差分に依存 |
| 簿価 | Drive 仕様では日本株買付は数量*単価+手数料、売付は -手数料抜き売値。米国株は手数料込み外貨額*為替レート、投信は数量/10000*単価+国内手数料 | 共通仕様では買付系は受渡金額ベース、売却系は -取得価格。外貨買付は `受渡金額 * レート - 手数料の消費税額` | 差分あり | `docs/trade-rules.md` / `docs/spec.md` の共通仕様と Drive 計算仕様が一致していない。どちらを正とするか先に決める必要がある |
| 銘柄ごとの残高 | 銘柄単位で簿価を累積 | 共通計算コアで銘柄単位に累積 | 概ね対応 | 簿価差分に連動して結果がずれる |
| FX2の期末簿価 | 列は用意。仕様上は空欄扱い | 共通計算コアで空欄 | 対応済み | なし |
| 金銭残高: 残高 | 円/ドルごとに対象取引を累積 | 共通計算コアで買付・出金をマイナス、売却・配当・入金などをプラス | 一部対応 | Drive 仕様の将来予測版にある入庫や追加ケースは未整理。最終見た目の列構成も未実装 |
| 金銭残高: 月次残高 | 月末行のみ残高を表示 | 共通計算コアで同年月の最終行に表示 | 対応済み | 表示列名・列順は最終見た目と未一致 |

## 必要PRの分割案

1. **仕様すり合わせ docs PR**
   - この差分表を起点に、Drive 仕様と `docs/spec.md` / `docs/trade-rules.md` の正本を揃える。
   - 特に `元金払戻金` / `元本払戻金`、`為替レート` / `レート`、`国内源泉税` / `国内源泉所得税` の名称を決める。

2. **楽天入力追加列・名称差分 PR**
   - 投信の追加列を検出・DB保存できるようにする。
   - 配当金・分配金CSVの手入力列名を Drive 仕様へ合わせるか、表記ゆれとして許容する。
   - `税金[USドル]`、`約定代金[USドル]`、`受付金額[現地通貨]` など、後続出力/計算で必要な元CSV列を保持する。

3. **楽天DBの元CSV列保持 PR**
   - 現状の共通モデル経由では失われる `market`、元の取引区分/売買区分、信用区分、弁済期限、税区分、各種元金額を楽天DBに保存する。
   - 後続の出力専用処理が `RAKUTEN_DB_HEADERS` から直接列を組み立てられる状態にする。

4. **楽天専用出力スキーマ PR**
   - `楽天日本株` / `楽天米国株` / `楽天投資信託` / `金銭残高（円）` / `金銭残高（ドル）` のヘッダー定義だけを追加する。
   - まずは列名・列順・表示対象を固定し、計算ロジック変更は入れない。

5. **元CSV列と追加列の楽天出力 PR**
   - 楽天DBから元CSV列・追加列を専用タブへ出す。
   - 共通 `BASE_HEADERS` の列名へ丸めず、Drive 仕様の列名で出力する。

6. **楽天計算列 PR**
   - 保有数、手数料の消費税額、平均取得単価、手数料抜き売値、取得価格、売却損益、簿価、銘柄ごとの残高、FX2の期末簿価を楽天専用列へ出す。
   - 米国株の `税金[USドル] * 為替レート`、投信追加手入力列、簿価式の正本を確定してから実装する。

7. **楽天最終見た目・表示制御 PR**
   - `4_楽天アウトプット用_最終的な見た目` の表示チェックに沿って列非表示、列順、タブ名、タブ順、書式を整える。
   - 既存の共通 writer 非表示ルールとは分ける。

8. **楽天出力回帰テスト PR**
   - 入力5種類、追加列、円/ドル残高、配当金/分配金、投信解約を含むテストを追加する。
   - GAS 上で実行する関数名と期待する出力列を明記する。

## この docs で確認したが、まだ実装しないこと

- コード変更はしない。
- 楽天専用出力のヘッダー定義、DBスキーマ拡張、計算式変更は後続PRへ分ける。
- Drive の実データサンプルを使った出力値検証は未実施。この docs は列仕様と現状実装の差分整理に限定する。
