# Codex Prompt Templates

このファイルは、Codex に投げるプロンプトのテンプレート集です。  
リポジトリでは `docs/codex-prompts.md` として置く想定です。

## 使い方

Codex には、毎回長い説明を書かずに次のように依頼します。

```text
docs/codex-prompts.md の T01 を使って進めてください。

対象ブランチ:
- develop

対象ファイル:
- src/app/source_routing_rakuten_phase1.gs
- src/test/test_rakuten_phase1.gs

目的:
- 楽天米国株の決済通貨判定が正しいか確認したい

補足:
- まだコード変更しないでください。
```

基本方針:

- まず「調査だけ」「方針だけ」で小さく始める
- 実装は対象ファイルを限定する
- ドキュメント更新は必要最小限にする
- `AGENTS.md` / `docs/codex-handoff.md` / `docs/decisions.md` は原則触らせない
- GAS本番反映前だけ `runAllTests` まで確認する

## T00: まず文脈を読ませるだけ

```text
AGENTS.md、docs/current-status.md、docs/TODO.md を読んで、
このプロジェクトの現在の状態・未解決課題・次にやるべきタスクを要約してください。

まだコード変更はしないでください。
推測で断定せず、根拠になったファイル名も添えてください。
```

## T01: 調査だけしてもらう

```text
以下の観点で調査してください。まだコード変更はしないでください。

目的:
- {{目的}}

対象ファイル:
- {{対象ファイル}}

確認してほしいこと:
- 既存仕様と矛盾していないか
- 影響範囲はどこか
- 修正が必要なら最小修正案は何か
- テストを追加/更新すべき場所はどこか

出力形式:
1. 結論
2. 根拠
3. 影響範囲
4. 最小修正案
5. 変更する場合の対象ファイル
6. 実行すべきテスト

制約:
- まだコード変更しない
- 関係ないファイルを読みに行きすぎない
- AGENTS.md、docs/codex-handoff.md、docs/decisions.md は触らない
```

## T02: 最小差分で実装してもらう

```text
以下の目的で、最小差分だけ実装してください。

目的:
- {{目的}}

対象ファイル:
- {{対象ファイル}}

期待する挙動:
- {{期待する挙動}}

制約:
- 既存関数名の互換性を壊さない
- GAS / V8 で動くコードにする
- 既存テストを壊さない
- 変更対象外のリファクタリングはしない
- AGENTS.md、docs/codex-handoff.md、docs/decisions.md は触らない
- ドキュメント更新は必要な場合のみ docs/TODO.md または docs/current-status.md の該当箇所だけにする

確認:
- 関連するテストを追加/更新してください
- 実行した確認コマンド/確認内容を最後に列挙してください
- Apps Script 上で必要な手動確認があれば列挙してください
```

## T03: PRレビューだけしてもらう

```text
PR #{{PR番号}} をレビューしてください。まだコード変更はしないでください。

重点的に見る観点:
- 既存仕様との矛盾
- GAS / V8 で動かないコードがないか
- UIとサーバー側の引数名・戻り値名が合っているか
- DBキー変更による互換性破壊がないか
- テスト不足
- マージ前に手動確認すべき項目

出力形式:
1. マージしてよいかの暫定判断
2. ブロッカー
3. できれば直したい点
4. 確認済みで問題なさそうな点
5. Codexに次に依頼すべき最小タスク
```

## T04: PR差分から危険箇所を洗い出す

```text
PR #{{PR番号}} の差分を見て、危険箇所だけを洗い出してください。
まだコード変更はしないでください。

特に確認すること:
- 既存のUI操作が壊れないか
- DBキーや設定名の変更で後方互換性が壊れないか
- 既存DBや過去の取込履歴が読めなくならないか
- 関数の削除で呼び出し元が残っていないか
- テストが本当に変更内容を固定しているか

出力形式:
- 危険度 高/中/低
- 該当ファイル
- 理由
- 推奨対応
```

```text
1. 推奨マージ順

3. 競合候補ファイル
4. 事前に直すべき点
5. マージ後の確認手順
```

```text
最後に:
```

## よく使う短縮呼び出し

### 調査だけ

```text
docs/codex-prompts.md の T01 を使ってください。
目的: {{目的}}
対象ファイル: {{対象ファイル}}
まだコード変更しないでください。
```

### 最小実装

```text
docs/codex-prompts.md の T02 を使ってください。
目的: {{目的}}
対象ファイル: {{対象ファイル}}
期待する挙動: {{期待する挙動}}
```

### PRレビュー

```text
docs/codex-prompts.md の T03 を使って、PR #{{PR番号}} をレビューしてください。
まだコード変更しないでください。
```

### バグ修正

```text
docs/codex-prompts.md の T07 を使ってください。
不具合: {{不具合}}
再現条件: {{再現条件}}
期待結果: {{期待結果}}
実際の結果: {{実際の結果}}
```

### ドキュメントだけ

```text
docs/codex-prompts.md の T12 を使ってください。

コードは変更しないでください。
```
