# 取引履歴CSV 4シート生成 Webアプリ仕様書

## 1. 目的

取引履歴CSVを入力として、新しい Google スプレッドシートを作成し、以下の 4 シートを自動生成する。

- 国内取引
- 外国取引
- 金銭残高（円）
- 金銭残高（ドル）

また、1シート目には元データを `元データ` シートとして保存する。

---

## 2. 入力

### 2.1 入力方法

以下の 2 通りをサポートする。

- CSVリンク
- ローカルCSVファイルアップロード

### 2.2 CSVの前提列

CSVには少なくとも以下の項目が含まれることを前提とする。

- 約定日
- 受渡日
- 商品
- 銘柄コード
- 銘柄名
- 摘要
- 取引区分
- 預り区分
- 発行通貨
- 数量
- 単価
- 受渡金額/決済損益
- 手数料（税込）
- レート
- 決済通貨
- 売買損益（円）

---

## 3. 出力シートの分類条件

| 出力シート | 条件 |
|---|---|
| 国内取引 | 商品が `株式` または `投信` |
| 外国取引 | 商品が `外株` |
| 金銭残高（円） | 決済通貨が `JPY` または空欄 |
| 金銭残高（ドル） | 決済通貨が `USD` |

---

## 4. 並び順

### 4.1 国内取引 / 外国取引

以下の順で昇順ソートする。

1. 商品
2. 銘柄名
3. 受渡日
4. 約定日
5. 取引区分優先順位

取引区分優先順位は `trade-rules.md` の定義に従う。

また、銘柄名が切り替わる位置に空白行を 1 行入れる。

### 4.2 金銭残高（円） / 金銭残高（ドル）

以下の順で昇順ソートする。

1. 受渡日
2. 約定日
3. 銘柄名

---

## 5. 国内取引 / 外国取引に追加する列

追加列の順番は以下とする。

1. 保有数
2. 手数料の消費税額
3. 平均取得単価
4. 手数料抜き売値
5. 取得価格
6. 売却損益
7. 簿価
8. 銘柄ごとの残高
9. FX2の期末簿価

各列の計算ルールは `trade-rules.md` を正とする。

---

## 6. 金銭残高（円）/ 金銭残高（ドル）の追加列

### 6.1 残高

累積計算する。

| 取引区分 | 計算 |
|---|---|
| 現物買付 / 現物再投 / 出金（振込） / 現物募集 | `受渡金額 × (-1)` |
| 現物売却 / 入金（利金） / 入金（配当金） / 償還 / 入金（振込） | `受渡金額` |
| その他 | 何もしない |

### 6.2 月次残高

- その行がその月の最後の行なら残高を入れる
- それ以外は空欄

---

## 7. 表示ルール

- 保有数 0 は `0表示 + 赤字`
- 手数料 0 は `0表示`
- 平均取得単価は `内部小数保持 / 表示整数`
- 銘柄ごとの残高は整数表示
- 金額列は基本的に整数表示
- レートは小数表示
- その銘柄の最後の取引行で、保有数が 0 より大きい場合、銘柄名セルを水色にする

---

## 8. 非表示列

### 8.1 国内取引

- 摘要
- 発行通貨
- レート
- 決済通貨

### 8.2 外国取引

- 摘要

---

## 9. アラート出力

Webアプリの実行結果画面にアラートログを表示する。

### 9.1 アラート対象

- 簿価計算時のレート未入力
- 対象外の取引区分
- 必要な前提値が無く計算できないケース
- 現物売却 / 現物買取で平均取得単価が無いケース

### 9.2 アラート文の要件

以下が分かる形式にする。

- どの項目の判定で起きたか
- 取引区分
- 銘柄名
- 受渡日

---

## 10. 実装上の注意

- この仕様書を唯一の正とする
- 変更履歴はこのファイルに書かない
- 変更履歴は別ドキュメントに分離する
- ChatGPT に再実装依頼するときは、`spec.md` と `trade-rules.md` をセットで渡す
