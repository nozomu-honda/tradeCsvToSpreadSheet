## この版で整理した主な内容

- 出力は **6シート**  
  `日本株 / 米国株 / 外債 / 投信 / 金銭残高（円） / 金銭残高（ドル）`
- `外債` は `米国株` から分離する
- 先頭側のタブ順は  
  `日本株 → 米国株 → 外債 → 投信`
- 入力方法は  
  `CSVリンク / スプレッドシートURLまたはID / ローカルCSVファイル`
- 一次受け枠も同じ3系統から作成可能
- 一次受け枠の赤セルは必須入力
- ただし `test DB` では赤セル必須入力バリデーションをスキップできる
- `test DB` は固定の確認用Spreadsheetへ再出力できる
- `入金（分配金）` は簿価・銘柄ごとの残高を増やさない
- 外貨買付系の簿価は  
  `受渡金額 × レート - 手数料の消費税額`
- docs は **合意仕様** と **現状コードとの差分** が分かるように整理した

## 運用ルール

- `spec.md` と `trade-rules.md` を仕様の正本とする
- `TODO.md` は引き継ぎメモ・保留事項・未反映差分の管理場所とする
- 実装変更時は、まず仕様を更新してからコードを修正する
- 次チャットへ渡すときは、この `docs` 一式をまとめて渡す
