# 株管理ツール ドキュメント

このページは、取引履歴CSV 4シート生成 Webアプリのドキュメント入口です。

## ドキュメント一覧

- [仕様書](spec.md)
- [取引区分別ルール表](trade-rules.md)

## 読み方

- 全体像、入力仕様、DB運用、ロールバック、表示仕様を確認したいとき  
  → [仕様書](spec.md)

- 計算ロジックや取引区分ごとの処理を確認したいとき  
  → [取引区分別ルール表](trade-rules.md)

## この版で反映済みの主な内容

- CSV前置き行の許可と、ヘッダー前実データのエラー化
- 税4列の追加
- 税列ヘッダー名の厳密一致
- 法人・口座単位のDB分割
- 追加先DB選択
- 最近の取込一覧と importId 単位のロールバック
- 論理削除方式のロールバックと `rolledBackAt` 記録
- DBリセット時のシート再作成による書式初期化
- 為替買付 / 為替売却、現物買取、入出金（振込）を含む現行残高仕様
- 投信の平均取得単価を 10000口基準で扱う仕様
- `元本払戻金` / `国内手数料（円）` / `現地手数料（円）` の追加
- 外株の `手数料抜き売値 = 単価 × 数量 × レート`
- 外貨買付系の簿価で、消費税額にレートを掛けない新仕様
- `元本払戻金 = true` のとき、分配金を通常の簿価加算とは別扱いにする仕様

## 運用ルール

- `spec.md` と `trade-rules.md` を仕様の正本とする
- 変更履歴や作業メモは別ファイルに分離する
- 実装変更時は、まず仕様を更新してからコードを修正する
- ChatGPT に再実装依頼するときは、このドキュメント群を渡す
