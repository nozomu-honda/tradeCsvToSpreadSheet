# 株管理ツール ドキュメント

このページは、取引履歴CSV 4シート生成 Webアプリのドキュメント入口です。

## ドキュメント一覧

- [仕様書](spec.md)
- [取引区分別ルール表](trade-rules.md)

## 読み方

- 全体像を確認したいとき  
  → [仕様書](spec.md)

- 計算ロジックや取引区分ごとの処理を確認したいとき  
  → [取引区分別ルール表](trade-rules.md)

## 運用ルール

- `spec.md` と `trade-rules.md` を仕様の正本とする
- 変更履歴や作業メモは別ファイルに分離する
- 実装変更時は、まず仕様を更新してからコードを修正する
- ChatGPT に再実装依頼するときは、このドキュメント群を渡す
