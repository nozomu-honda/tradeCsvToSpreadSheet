## この版で反映済みの主な内容

- 入力方法を **CSVリンク / スプレッドシートURLまたはID / ローカルCSVファイル** の3系統に整理
- 一次受け枠作成を **CSVリンク / スプレッドシートURLまたはID / ローカルCSVファイル** から可能に整理
- 出力を **5シート → 6シート** に変更
- `外債` を `米国株` から分離し、**外債シート** を新設
- 出力タブ順を **日本株 → 米国株 → 外債 → 投信** が先頭側に来る前提へ更新
- `test DB` では赤セル必須入力バリデーションをスキップできる仕様を反映
- `test DB` は固定の確認用スプレッドシートへ再出力できる前提を反映
- `入金（分配金）` は簿価・銘柄ごとの残高を増やさない仕様へ更新
- 外貨買付系の簿価計算を  
  **`受渡金額 × レート - 手数料の消費税額 × レート`**  
  とする最新仕様へ更新
- `元本払戻金` / `国内手数料（円）` / `現地手数料（円）` を含む追加7カラム前提を反映
- 前置き行許可、ヘッダー厳密一致、DB分割、ロールバック、DBリセット、固定Spreadsheet再利用テスト運用を反映
