# CSVから4シート生成する Apps Script Webアプリ

CSVリンク、またはローカルCSVアップロードから新しい Google スプレッドシートを作成し、1シート目に元データを入れたうえで、以下の4シートを自動生成する Google Apps Script Webアプリです。

- 国内取引
- 外国取引
- 金銭残高（円）
- 金銭残高（ドル）

## 概要

このアプリは、取引履歴CSVをもとに新しいスプレッドシートを作成し、元データを整理したシートを自動生成します。

入力方法は2つあります。

- CSVリンクを指定
- ローカルのCSVファイルをアップロード

生成されるスプレッドシートでは、1枚目のシート名を `元データ` とし、その内容をもとに4つの出力シートを作成します。

## 生成されるシート

### 1. 国内取引
対象:
- 商品が `株式`
- 商品が `投信`

### 2. 外国取引
対象:
- 商品が `外株`

### 3. 金銭残高（円）
対象:
- 決済通貨が空欄
- 決済通貨が `JPY`

### 4. 金銭残高（ドル）
対象:
- 決済通貨が `USD`

## 並び順

### 国内取引 / 外国取引
以下の順で昇順ソートします。

1. 商品
2. 銘柄名
3. 受渡日
4. 約定日

また、銘柄名が切り替わるたびに空白行を1行挿入します。

### 金銭残高（円） / 金銭残高（ドル）
以下の順で昇順ソートします。

1. 受渡日
2. 約定日
3. 銘柄名

## 追加列

### 国内取引 / 外国取引
元データ列の右側に以下を追加します。

- 保有数
- 手数料の消費税額
- 平均取得単価
- 手数料抜き売値
- 取得価格
- 売却損益
- 簿価
- 銘柄ごとの残高
- FX2の期末簿価

### 金銭残高（円） / 金銭残高（ドル）
元データ列の右側に以下を追加します。

- 残高
- 月次残高

## 0表示の扱い

以下は **0でも表示** します。

- 保有数
- 手数料（税込）

表示形式側でも 0 が消えないようにしています。

一方で、以下のような「対象外」や「未計算」の列は、条件を満たさない場合は空欄のままです。

- 平均取得単価
- 手数料抜き売値
- 取得価格
- 売却損益
- FX2の期末簿価

## CSVの前提

以下のようなヘッダーを含むCSVを想定しています。

- 約定日
- 受渡日
- 商品
- 銘柄コード
- 銘柄名
- 摘要
- 取引区分
- 預り区分
- 発行通貨
- 数量
- 単価
- 受渡金額/決済損益
- 手数料（税込）
- レート
- 決済通貨
- 売買損益（円）

先頭にタイトル行や件数行などがあっても、実データのヘッダー行を自動検出します。
